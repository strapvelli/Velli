Backend setup

GitHub Pages only hosts the front end. To automate monitoring, deploy a separate HTTPS backend with a Telegram listener, deduplication, odds-provider integration, and a persistent database. Keep bot tokens, Telegram session credentials, and API keys on the server, never in this HTML or public GitHub repository.

Suggested pipeline: Telegram listener → normalized tip queue → match/market validation → odds lookup → probability model → paper-bet database → dashboard API.

A continuously running backend usually requires hosting. Free tiers can sleep or limit usage, so uninterrupted monitoring may not be free.

Privacy & safety

This is a paper-only analysis tool. No real-money betting, wager placement, or bookmaker account integration. Do not scrape channels without permission or bypass access restrictions.
